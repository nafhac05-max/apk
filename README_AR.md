# Carnet de stage — تطبيق Android

هذا المشروع يحزم ملف HTML الأصلي داخل تطبيق Android باستخدام WebView محلي، ولا يحتاج إلى اتصال بالإنترنت لتشغيل الدفتر. أزلنا تحميل خطوط Google الخارجية كي لا يعتمد العرض على الشبكة؛ سيستخدم الجهاز خطوط النظام البديلة.

## بناء APK عبر GitHub (من دون Android Studio)
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع (بما فيها `.github`).
3. افتح تبويب **Actions** ووافق على تفعيل workflows إن طُلب ذلك.
4. شغّل **Build Android APK** عبر **Run workflow**، أو ادفع commit إلى `main`/`master`.
5. بعد انتهاء البناء افتح نتيجة التشغيل، ثم نزّل Artifact باسم `carnet-de-stage-apk`.
6. فك ملف ZIP الناتج، وانقل `app-debug.apk` إلى هاتف Android وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

## الخصائص
- المحتوى يعمل محلياً من داخل التطبيق؛ لا توجد صلاحية إنترنت في التطبيق.
- الحفظ التلقائي عبر `localStorage` داخل WebView.
- استيراد نسخة JSON من منتقي ملفات Android.
- تصدير نسخة JSON عبر نافذة حفظ Android.
- الطباعة / الحفظ PDF عبر خدمة الطباعة في Android.

## ملاحظة مهمة
هذا APK تجريبي موقّع بمفتاح debug تلقائياً من Gradle، مناسب للتثبيت الشخصي والاختبار. احتفظ بنسخ JSON الاحتياطية في مكان آمن. لا تُدخل بيانات تعريفية حقيقية للمريضات إلا وفق سياسة المؤسسة الصحية وقواعد حماية البيانات المعمول بها. المحتوى السريري في الدفتر لم تتم مراجعته طبياً ضمن عملية التغليف هذه.
